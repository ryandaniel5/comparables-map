# Lease Comparables Map

Interactive map showing lease and sales comparables for 4040 & 4120 N MLK Blvd, North Las Vegas, NV.

## Features
- ✅ Interactive Leaflet.js map with pan & zoom
- ✅ Sidebar with comparable property listings
- ✅ Click to navigate to properties and view details
- ✅ Download map as PNG or PDF
- ✅ Live at: https://ryandaniel5.github.io/comparables-map/

## How to Use in Google Slides

1. Go to **Google Slides**
2. Click **Insert → Embed**
3. Paste this URL: `https://ryandaniel5.github.io/comparables-map/`
4. Click **Embed**

Users can click the link to open the interactive map in a new tab, or click the download button to export as PNG/PDF.
